FAQ

Frequently Asked Question

To download certificate, following requirement should be met :
  1. Cluster PO Number is Available
  2. RFS Homepass Data is Available
  3. Full OPM Approve 2 status is "Approved"
  4. Certificate has been sent by EMR Document Control
Data Completion :
  1. (Vendor) Data Not Complete? Contact EMR Doc. Control Team
  2. (Vendor) Data Difference? Contact EMR Doc. Control Team
  3. (Vendor) Cluster Not Listed? Request to EMR SND to manually add by clicking "RFS" button in DRM Menu
  4. (Doc. Control EMR) Data Not Updated? Confirm Data in Dbase Implementation is Complete then Click "Update From Dbase Implementation" Button or Asks Planning Team to Manually Update Data
